# Correspondência com a imagem adicional

Os 45 itens da terceira imagem foram comparados com o projeto. As ferramentas das duas imagens anteriores continuam no catálogo. O leitor também possui acesso permanente pela barra lateral.

| PDF para PDF/A | PDF para PDF/A; OCRmyPDF |

| PDF para PPT | PDF para PowerPoint; texto editável ou páginas como imagens |
| Word para PDF | Word para PDF; LibreOffice |
| Excel para PDF | Excel para PDF; ajuste à largura e orientação |

Achatar não remove informações sensíveis: para isso, use Ocultar PDF. Uma assinatura visual não é uma assinatura digital com certificado. O acesso ao Sign.com não inclui conta, plano pago, API privada ou envio automático de documentos.

Os requisitos de execução e as evidências de testes ficam em [VALIDACAO.md](VALIDACAO.md). Presença no catálogo não comprova testes com equipamento físico ou disponibilidade de modelos Apple. Conversões complexas podem alterar a composição; Pages exige o aplicativo da Apple e a IA exige Apple Intelligence disponível.
